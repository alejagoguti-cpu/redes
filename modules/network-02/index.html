RIBB · misma red finalscroll = prender / apagar capas
La red no cambia. Durante el recorrido se apagan y prenden capas sobre esta misma visualización.
01 · TERRITORIO

Primero ubicamos dónde buscar.

Selecciona un sector. La red todavía no afirma presencia: solo plantea el contexto espacial que luego debe comprobarse.

02 · GIS DE ARBOLADO Y VEGETACIÓN

Definimos las condiciones espaciales y la vegetación disponible.

La capa GIS permite reconocer plantas, arbolado y estructuras vegetales disponibles en el área de estudio. Esta es la base espacial sobre la que después contrastamos la presencia de organismos.

03 · PRESENCIA GEOREFERENCIADA

Verificamos qué taxones tienen evidencia territorial.

eBird + iNaturalist + SiB + GBIF sirven para verificar avistamientos y presencia georreferenciada. Para cada registro revisamos coordenada, fecha, precisión e identificación; aparecer en una base no basta para afirmar presencia local.

04 · RIBB

Con los taxones territoriales, buscamos interacciones documentadas.

Una vez sabemos qué taxones tienen evidencia territorial, consultamos RIBB para identificar qué relaciones están documentadas entre ellos: visita floral, herbivoría, depredación, dispersión, parasitismo y otras interacciones.

05 · CÓDIGO BIOSCI + VALIDACIÓN LOCAL

Complementamos relaciones, pero no confundimos posibilidad con presencia.

Código Biosci funciona como fuente complementaria para explorar relaciones biológicas y ecológicas. Solo entran como presencia local confirmada los registros cuya coordenada o geometría realmente intersecta el área de estudio. “Bogotá” o un dataset que incluya Kennedy no son suficientes por sí solos.

06 · MODELO DE NICHO

Cruzamos especie + vegetación + espacio + interacción.

Solo después de cruzar la especie registrada, la vegetación disponible, su posición espacial y la interacción documentada formulamos hipótesis sobre cómo se organiza la vida en Kennedy.
