La vida se entiende viendo quién se relaciona con quién.

La misma red que ves al final aparece desde el comienzo. Durante el recorrido se descompone por capas para explicar cómo está construida.

01 · BASE VEGETAL

Primero aislamos plantas y vegetación.

La red se reduce a los organismos que funcionan como recurso, hospedero, sustrato o soporte espacial. Aquí se conecta con la capa GIS de arbolado y vegetación.

02 · INVERTEBRADOS

Luego aparecen los organismos que visitan, consumen y parasitan.

Se encienden invertebrados junto a plantas para leer visita floral, herbivoría, oviposición y otras relaciones documentadas.

03 · AVES Y VERTEBRADOS

La red gana profundidad trófica.

Se incorporan aves y otros vertebrados para mostrar cómo el sistema se extiende más allá de las relaciones planta-insecto.

04 · MICROORGANISMOS Y HONGOS

La red también tiene capas menos visibles.

Cuando la base tiene evidencia, se activan microorganismos y hongos. No se inventan relaciones ausentes.

05 · TIPO DE INTERACCIÓN

Después descomponemos la red por proceso ecológico.

Selecciona una relación para ver cómo cambia la estructura.

06 · CALIDAD DE EVIDENCIA

No todos los vínculos tienen el mismo soporte.

Filtra por calidad para distinguir qué relaciones están mejor documentadas.

07 · SISTEMA COMPLETO

Finalmente volvemos a encender toda la red.

Ahora el enjambre puede leerse como la suma de capas ecológicas, procesos e incertidumbres que acabamos de separar.
