# Módulos de Red (`modules/`)

Esta carpeta está estructurada para hospedar los diferentes sub-módulos y proyectos de red:

```
modules/
├── network-01/          # Escala metropolitana / visualizaciones 2D
├── network-02/          # Métricas e indicadores de red
├── network-03/          # Discurso vs Realidad (topología de redes)
├── network-04/          # Macromodelos y nodos de impacto
├── network-05/          # Navegador multiescalar
└── README.md
```

Cada subcarpeta puede contener su propio `index.html` consumiendo el `css/sidebar.css` relativo (`../../css/sidebar.css`).
