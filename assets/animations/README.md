# Animaciones y Visualizaciones (`assets/animations/`)

Directorio organizado para subir archivos y scripts de animación de red:

- **`canvas/`**: Scripts de simulación gráfica con HTML5 Canvas o WebGL.
- **`threejs/`**: Escenas 3D de grafos y redes complejas.
- **`svg/`**: Animaciones CSS / SMIL en vectores de red.
- **`lottie/`**: Archivos de animación `.json` para la interfaz.
